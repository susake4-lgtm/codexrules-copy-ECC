# Session Save Handoff

Use this skill before ending a long or complex working session.

## Announce

Start by stating that you are using `session-save-handoff` to preserve continuation-ready context.

## Workflow

1. Capture the current goal.
2. Capture completed work.
3. Capture remaining work.
4. Capture key files.
5. Capture unresolved risks.
6. Capture the recommended next action.

## Output

Always report:

1. current goal
2. completed work
3. remaining work
4. key files
5. unresolved risks
6. recommended next step
